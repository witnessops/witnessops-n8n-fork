# WitnessOps fonts

These WOFF2 files are unmodified copies from `witnessops-web` at
`0d88485b889adf12969266911937b340a0ed9da3`.

Inter 400, 500, and 600 come from Fontsource 5.2.8. IBM Plex Mono 400 and 500
come from Fontsource 5.2.6. The Latin and Latin Extended subsets are included.
The box-drawing subsets come from the official Google Fonts WOFF2 files.
The adjacent license files apply to these fonts.
